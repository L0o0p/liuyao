# 六爻基础：当前产品功能文档

本文描述分支 `feat/chapters-ia`（worktree `../liuyao-srs`）上的产品现状，用作 UI/UX 重新设计的输入。第 8 节的 8.1、8.2、8.3 已经实现，8.4 暂缓。

## 1. 产品定位

帮助初学者把六爻断卦需要的基础对应关系记熟：天干地支属性、五行生克、地支刑冲合害、十二长生、六十四卦卦象。

核心学习方式是间隔重复。新知识按小组引入：先看整组对照表和口诀，再逐条答题；答对后间隔拉长，答错很快再出现。

目标用户：刚接触六爻、需要大量记忆对照表的人。使用场景以手机上每天几分钟的碎片时间为主。

纯本地应用，无账号、无联网功能。学习数据可以导出成文件，换机时再导入。

## 2. 信息架构

底部三个页签，默认打开「今日」：

| 页签 | 作用 |
|---|---|
| 今日 | 今天该复习多少、今天新学哪一组，一键开始 |
| 章节 | 按学习顺序列出 6 章；每章有对照表、口诀、掌握情况、小组进度和「练这一章」 |
| 我的 | 连续学习天数、整体掌握度、导入导出学习数据、清空卡片 |

章节顺序：五行生克 → 天干 → 地支 → 刑冲合害 → 十二长生 → 六十四卦。没有子菜单，也没有单独的「综合练习」入口，跨章节混合由今日承担。

## 3. 核心概念

**知识点**：一条固定的对应关系，例如「寅的五行是木」「讼的卦象是天水」。每条有唯一键 `题型:输入`，如 `zhi_wuxing:寅`、`gua_to_xiang:讼`。目录共 382 条。

**规则卡**：十二长生不按「日支 × 爻支」的 144 种组合记，而是挂在 17 条规则上：12 条阶段顺序（`changsheng_stage:长生` … `changsheng_stage:养`）和 5 条五行长生起点（`changsheng_start:木` 等：木长生在亥，火在寅，金在巳，水、土在申）。规则卡也是知识点，计入掌握数。

**小组**：每章拆成若干小组，按章节顺序排成一条线，共 33 组，例如「天干五行」「三刑与自刑」「乾宫八卦」。每组有标题、所含知识点（4 到 16 条）、相关的对照表和一句口诀。每个知识点恰好属于一个小组。

**题目**：知识点的一种考法。普通知识点的正确答案固定；另外最多 3 个错误选项每次重新随机抽取，并打乱顺序。阴阳题只有「阳」「阴」两个选项。规则卡多数时候出推算题（「日支午、爻支酉，处于十二长生的哪个阶段？」），每次随机抽一组依赖这条规则的日支和爻支；约四分之一的时候直接问规则（「金的长生在哪个地支？」「十二长生里，『病』之后是哪个阶段？」）。

**复习卡片**：每条知识点一张，记录状态（学习中 / 复习中）、下次到期时间、间隔天数、答错次数、复习次数、连续答对次数。无论从今日还是章节进入，答题都更新同一张卡片。推算题的评分只记在出题所依据的那张规则卡上。

**已掌握**：处于复习状态，且间隔不少于 21 天。

## 4. 页面与流程

### 4.1 今日

- 两个数字卡：「到期复习」「今天新学」，下面一行写今天的小组，例如「今天新学：天干五行（10 条）」。
- 「开始」按钮：进入练习，先做到期的，再学今天的小组。
- 每天自动引入 1 组：取第一个还有没学过的知识点的小组。当天引入过一组后不再自动引入，这一行显示「今天的新组已经学过」；全部引入完时显示「全部小组都已学过」。
- 到期和新学都为 0 时显示「今天已经学完」，以及两个次要按钮：「再学一组：地支五行（12 条）」（还有新组时才出现，不受每天一组的限制）和「去章节巩固」（跳到章节页）。

### 4.2 章节列表

每章一张卡：序号、标题、「已掌握 X/Y」、一句口诀摘要、掌握进度条。点卡片进入章节详情。

### 4.3 章节详情

- 上半部分：本章口诀摘要和全部对照表，表格可横向滚动。
- 「本章掌握情况」：已掌握 / 学习中 / 未学三项计数、进度条、「练这一章」。
- 「本章小组」：按引入顺序列出本章小组，每组显示「已学 X/Y · 已掌握 Z」，整组都学过时打勾。
- 右上角菜单「清空本章卡片」（二次确认）。

「练这一章」只练本章知识点：到期或学习中的在前，其余按离到期从近到远，没学过的排在最后；今天没有到期也能继续练，不受今日每天一组的限制。没学过的知识点在这里逐条先看教学卡。六十四卦每答 16 题弹一次「休息一下」，可继续或退出，只影响界面节奏。

### 4.4 练习页（今日和章节共用）

顶部：标题、「查表」、当前题号 / 本次总题数。

每道题的流程：

1. **小组引入**（仅今日练到新组的第一个知识点前出现一次）：「今日新学」、组标题、条数、整组对照表、口诀，按钮「开始逐条练习」。通过小组引入的知识点不再逐条显示教学卡。
2. **教学卡**（这条知识从未被评分过、且不是通过小组引入时出现）：标题、结论（如「甲对应木」「金的长生在巳」）、口诀或说明，按钮「记住了，开始答题」。
3. **答题卡**：题干，2 到 4 个选项按钮。不能左右滑动换题。
4. **答对**：选项变绿，显示「正确！」和正确答案，短暂停顿后自动下一题，轻震动。
5. **答错**：所选项变红、正确项变绿，显示正确答案和讲解，中等震动；讲解下方有「查表」。点「下一题」继续。十二长生推算题的讲解按步骤写：「日支午属火 → 火长生在寅 → 从寅顺数到酉：寅长生、卯沐浴、辰冠带、巳临官、午帝旺、未衰、申病、酉死 → 死」。
6. **本次结束**：弹窗「本次练完了」，返回上一页。

答错过的题要连续答对 2 次才离开本次队列，中间答错则重新计数；从未答错过的题答对一次即可。需要再练的题插到本次队列末尾，规则卡重练时会换一组日支和爻支。

### 4.5 查表

练习页顶部和答错讲解里的「查表」直接打开当前题所属章节的全部对照表，返回后还在原题。在答题卡上查表的时间不计入答题用时。

| 章节 | 表 |
|---|---|
| 五行生克 | 五行、所生、所克 |
| 天干 | 天干、阴阳、五行、方位、季节、月份、时辰 |
| 地支 | 地支属性（阴阳、五行、方位、季节、月份、时辰、钟点）；十二支指诀 |
| 刑冲合害 | 六合、三合、三刑、自刑、六冲、六害、相破 |
| 十二长生 | 阶段顺序、各五行长生起点 |
| 六十四卦 | 卦名、卦象（上卦+下卦）、八卦符号 |

### 4.6 我的

- 连续学习天数（按本地日历日；今天还没学时从昨天往前数）。
- 整体掌握度：已掌握 / 学习中 / 未学和进度条，以及已掌握的定义。
- 学习数据：「导出学习数据」（系统分享面板发出一个 JSON 文件）、「导入学习数据」（选择文件后与本机合并，较新的记录胜出，不覆盖本机较新的数据；旧版本导出的备份也能导入）。
- 设置：「清空全部卡片」（二次确认）。
- 右上角刷新。

## 5. 复习规则

| 情况 | 结果 |
|---|---|
| 新知识第一次出现 | 学习中，立刻到期 |
| 答错 | 回到学习中，10 分钟后到期，本次队列末尾再出现 |
| 答错后第一次答对 | 记一次答对，间隔先不拉长，本次还要再答一次 |
| 答对（没失误过，或连续第二次答对），≤ 8 秒 | 学习中 → 复习，间隔 1 天；复习中则间隔 × 2.5，最多 180 天 |
| 同上，> 8 秒 | 仍算答对，但这次间隔增长减半 |

答题用时从答题卡出现算起，扣掉查表的时间。

## 6. 数据与迁移

- 全部数据存在本机。每张卡片一个键，带更新时间；删除写成带删除标记的记录，为将来同步预留。数据版本为 4。
- 当天引入过哪些小组存在一个本地记录里，不参与同步也不导出；换机后丢失最多让当天多引入一组。
- 更早版本的错题和熟练度在首次启动时自动转换成卡片：旧错题立刻到期；熟练度 60 分以上直接进入复习。
- 版本 3 的十二长生卡（按日支_爻支记）在启动时并到规则卡上：每张旧卡按日支五行并到起点卡、按推出的阶段并到阶段卡；同一张规则卡收到多张旧卡时取最弱的一张（学习中弱于复习中，其次间隔更短、到期更早），答错次数和复习次数取最大。旧卡写删除标记。
- 导出文件为版本 4。导入接受版本 2、3、4：版本 2 先按启动迁移的规则转成卡片，版本 2、3 里的十二长生卡再按上一条并到规则卡。

## 7. 现有的体验短板（重新设计时重点考虑）

1. 视觉沿用默认 Material 紫色主题，没有传统文化的气质，也没有统一的设计语言。
2. 今日页只有两个数字、一行小组名和一个按钮，缺少今日目标完成度等激励信息；连续学习天数只在「我的」里。
3. 练习页没有本次进度条；答错讲解是纯文字，十二长生的推算步骤也只是一行文字。指诀、方位、六十四卦都适合图示（手掌图、方位盘、卦爻图），目前都没有。
4. 六十四卦卦象只用「天水」这样的文字和 ☰☵ 字符，没有画出六爻。
5. 小组引入页、教学卡和答题卡布局各不相同，切换生硬。
6. 章节详情能看到小组进度，但看不出具体哪些知识点还弱。
7. 没有深色模式，没有字号调整。
8. 没有引导页，首次打开不知道这个应用怎么用。

## 8. UX 重构方向

### 8.1 导航：今日 / 章节 / 我的（已完成）

- 「学习」和「图鉴」合并为「章节」，「进度」改为「我的」。
- 章节按学习顺序排列：五行生克 → 天干 → 地支 → 刑冲合害 → 十二长生 → 六十四卦。
- 章节详情页：上半部分是对照表和口诀，下半部分是本章掌握情况和「练这一章」。
- 去掉「天干地支基础」子菜单和两个「综合练习」入口。跨章节混合由今日承担。
- 「我的」：连续学习天数、整体掌握度、导入导出学习数据、设置（含清空卡片）。
- 做题页和答错讲解里有「查表」入口，直接打开这道题所属章节的对照表，看完返回原题。

### 8.2 规则类内容按规则排期（已完成）

- 十二长生的复习卡片挂在规则上：5 条「某五行的长生在某支」和 12 条阶段顺序，共 17 条，取代原来的 144 条日支×爻支组合。
- 题目仍考推算（「日支午、爻支酉，处于哪个阶段」），偶尔直接问规则。答错时按步骤展示：日支五行 → 长生起点 → 顺数到爻支。评分记到这道题依赖的规则卡片上。
- 六冲、六合等只有几对的关系仍按对照记忆。

### 8.3 新知识按小组引入（已完成）

- 每章拆成若干小组，例如「天干五行」「地支五行」「乾宫八卦」。
- 引入一组时，先看整组表格和口诀，再逐条考。
- 今日默认每天引入 1 组，取代每天 5 条；学完后可以「再学一组」。

### 8.4 暂缓

- 图示题（手掌点选指节、方位盘、点爻画卦）放到下一阶段。本阶段先把结构改完。

## 9. 设计约束

- 技术栈 Flutter，主要平台 iOS，兼顾 Android。设计稿最终要用 Flutter 组件重写，不直接使用导出的 HTML。
- 手机竖屏优先，要照顾小屏（高度 < 700）。
- 中文为主，题干和选项会出现「申 子 辰」「无名指 - 根部」「23-1」这类较长文本，选项按钮要能容纳两行。
- 选项数量 2 到 4 个不等。
- 练习页不能靠左右滑动切题。
- 知识内容与出题规则已定，重设计不改动这些内容，只改呈现和流程。
