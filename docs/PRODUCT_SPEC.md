# 六爻基础：当前产品功能文档

本文描述分支 `feat/teaching-cards`（worktree `../liuyao-srs`）上的产品现状，用作 UI/UX 重新设计的输入。「错题需连续答对 2 次才离开本次练习」正在开发，下文单独标注。

## 1. 产品定位

帮助初学者把六爻断卦需要的基础对应关系记熟：天干地支属性、五行生克、地支刑冲合害、十二长生、六十四卦卦象。

核心学习方式是按单条知识做间隔重复。第一次见到先看教学卡，再答题；答对后间隔拉长，答错很快再出现。

目标用户：刚接触六爻、需要大量记忆对照表的人。使用场景以手机上每天几分钟的碎片时间为主。

纯本地应用，无账号、无联网功能。

## 2. 信息架构

底部四个页签，默认打开「今日」：

| 页签 | 作用 |
|---|---|
| 今日 | 今天该复习多少、可新学多少，一键开始 |
| 学习 | 按模块进入练习 |
| 图鉴 | 查阅全部对照表，不计入学习记录 |
| 进度 | 按模块看掌握情况，清空卡片 |

学习页有一层子菜单：「天干地支基础」下面再分 6 个模块。

## 3. 核心概念

**知识点**：一条固定的对应关系，例如「寅的五行是木」「讼的卦象是天水」。每条有唯一键 `题型:输入`，如 `zhi_wuxing:寅`、`gua_to_xiang:讼`。

**题目**：知识点的一种考法。正确答案固定；另外最多 3 个错误选项每次重新随机抽取，并打乱顺序。阴阳题只有「阳」「阴」两个选项。

**复习卡片**：每条知识点一张，记录状态（学习中 / 复习中）、下次到期时间、间隔天数、答错次数、复习次数。无论从今日还是模块进入，答题都更新同一张卡片。

**已掌握**：处于复习状态，且间隔不少于 21 天。

## 4. 页面与流程

### 4.1 今日

- 两个数字卡：「到期复习」「今天可新学」。
- 「开始」按钮：进入练习，先做到期的，再做今天的新知识。
- 每天新学上限 5 条，跨天重置。新知识按目录顺序引入。
- 两者都为 0 时显示「今天已经学完」，以及「去模块巩固」按钮（跳到学习页）。

### 4.2 学习（模块列表）

根目录模块：

1. 六十四卦
2. 天干地支基础（子菜单，见下）
3. 十二支指诀
4. 六合三合六冲
5. 十二长生
6. 综合练习

「天干地支基础」子菜单：

1. 天干地支综合练习
2. 天干地支五行
3. 天干地支阴阳
4. 方位对应（方位、季节、月份）
5. 时间对应（时辰、钟点）
6. 五行生克

点进模块后只练该模块的知识点：

- 顺序：到期或学习中的在前，其余按离到期从近到远，没学过的排在最后。
- 今天没有到期也能继续练。
- 不占用今日 5 条新学额度。
- 六十四卦每答 16 题弹一次「休息一下」，可继续或退出。只影响界面节奏，不记录。

### 4.3 练习页（今日和模块共用）

顶部：标题、当前题号 / 本次总题数。

每道题的流程：

1. **教学卡**（仅在这条知识从未被评分过时出现）：标题、结论（如「甲对应木」）、口诀或说明，按钮「记住了，开始答题」。
2. **答题卡**：题干，2 到 4 个选项按钮。不能左右滑动换题。
3. **答对**：选项变绿，显示「正确！」和正确答案，短暂停顿后自动下一题，轻震动。
4. **答错**：所选项变红、正确项变绿，显示正确答案和教学说明，中等震动。点「下一题」继续。这道题会再插入本次队列末尾。
5. **本次结束**：弹窗「本次练完了」，返回上一页。

用时也计入评分：答对且不超过 8 秒算快，超过 8 秒间隔增长减半。

> 开发中：答错过的题要连续答对 2 次才离开本次队列，中间答错则重新计数。从未答错过的题答对一次即可。

### 4.4 图鉴

章节列表，每章一个标题和一句口诀摘要。点进去是一个或多个对照表，表格可横向滚动。

| 章节 | 表 |
|---|---|
| 十天干 | 天干、阴阳、五行、方位、季节、月份、时辰 |
| 十二地支 | 地支、阴阳、五行、方位、季节、月份、时辰、钟点 |
| 五行生克 | 五行、所生、所克 |
| 十二支指诀 | 地支、指节 |
| 刑冲合害 | 六合、三合、三刑、自刑、六冲、六害、相破 |
| 十二长生 | 阶段顺序、各五行长生起点 |
| 六十四卦 | 卦名、卦象（上卦+下卦）、八卦符号 |

### 4.5 进度

- 总体卡：已掌握 / 学习中 / 未学，以及掌握比例进度条。
- 说明文字：已掌握的定义。
- 每个模块一张卡：图标、名称、三项计数、进度条。点卡片进入该模块练习；可单独清空该模块卡片（二次确认）。
- 底部「清空全部卡片」（二次确认）。
- 右上角刷新。

## 5. 复习规则

| 情况 | 结果 |
|---|---|
| 新知识第一次出现 | 学习中，立刻到期 |
| 答错 | 回到学习中，10 分钟后到期，本次再出现一次 |
| 答对，≤ 8 秒 | 学习中 → 复习，间隔 1 天；复习中则间隔 × 2.5，最多 180 天 |
| 答对，> 8 秒 | 仍算答对，但这次间隔增长减半 |

## 6. 数据与迁移

- 全部数据存在本机。每张卡片一个键，带更新时间，为将来同步预留。
- 旧版本的错题和熟练度在首次启动时自动转换成卡片：旧错题立刻到期；熟练度 60 分以上直接进入复习。
- 应用内没有导入导出入口。

## 7. 现有的体验短板（重新设计时重点考虑）

1. 视觉沿用默认 Material 紫色主题，没有传统文化的气质，也没有统一的设计语言。
2. 今日页只有两个数字和一个按钮，缺少连续学习天数、今日目标完成度等激励信息。
3. 练习页没有本次进度条；答错后的说明是纯文字。指诀、方位、六十四卦都适合图示（手掌图、方位盘、卦爻图），目前都没有。
4. 六十四卦卦象只用「天水」这样的文字和 ☰☵ 字符，没有画出六爻。
5. 教学卡和答题卡是两种完全不同的布局，切换生硬。
6. 进度页是一长串模块卡片，看不出具体哪些知识点还弱。
7. 学习页有一层子菜单，「天干地支基础」和「综合练习」的关系不直观。
8. 没有深色模式，没有字号调整。
9. 没有引导页，首次打开不知道这个应用怎么用。

## 8. 已确定的 UX 重构方向

### 8.1 导航：今日 / 章节 / 我的

- 「学习」和「图鉴」合并为「章节」，「进度」改为「我的」。
- 章节按学习顺序排列：五行生克 → 天干 → 地支 → 刑冲合害 → 十二长生 → 六十四卦。
- 章节详情页：上半部分是对照表和口诀，下半部分是本章掌握情况和「练这一章」。
- 去掉「天干地支基础」子菜单和两个「综合练习」入口。跨章节混合由今日承担。
- 「我的」：连续学习天数、整体掌握度、导入导出学习数据、设置（含清空卡片）。
- 做题页和答错讲解里有「查表」入口，直接打开这道题所属章节的对照表，看完返回原题。

### 8.2 规则类内容按规则排期

- 十二长生的复习卡片挂在规则上：5 条「某五行的长生在某支」和 12 条阶段顺序，共 17 条，取代现在的 144 条日支×爻支组合。
- 题目仍考推算（「日支午、爻支酉，处于哪个阶段」）。答错时按步骤展示：日支五行 → 长生起点 → 顺数到爻支。评分记到这道题依赖的规则卡片上。
- 六冲、六合等只有几对的关系仍按对照记忆。

### 8.3 新知识按小组引入

- 每章拆成若干小组，例如「十天干五行」「十二地支五行」「乾宫八卦」。
- 引入一组时，先看整组表格和口诀，再逐条考。
- 今日默认每天引入 1 组，取代每天 5 条。

### 8.4 暂缓

- 图示题（手掌点选指节、方位盘、点爻画卦）放到下一阶段。本阶段先把结构改完。

## 9. 设计约束

- 技术栈 Flutter，主要平台 iOS，兼顾 Android。设计稿最终要用 Flutter 组件重写，不直接使用导出的 HTML。
- 手机竖屏优先，要照顾小屏（高度 < 700）。
- 中文为主，题干和选项会出现「申 子 辰」「无名指 - 根部」「23-1」这类较长文本，选项按钮要能容纳两行。
- 选项数量 2 到 4 个不等。
- 练习页不能靠左右滑动切题。
- 知识内容与出题规则已定，重设计不改动这些内容，只改呈现和流程。
